# Research: M6 System Hacking

Scope: the four sections in `content/modules/m06/meta.json` (Gaining Access, Escalating Privileges, Maintaining
Access, Clearing Logs), read as one attack lifecycle. The public CEH v13 course page lists the module's key topics
(password cracking, password attacks and tools, vulnerability exploitation, Metasploit, AI-powered exploitation
tools, buffer overflow and its detection tools, AD enumeration, privilege escalation and its tools, executing
applications, keyloggers, spyware, rootkits, steganography, steganalysis and detection tools, maintaining
persistence, Linux and Windows post exploitation, covering tracks, clearing logs, track-covering tools). That list is
used for scope only; all wording below is ours, from public primary sources.

Level: recognition and defense, as in a certification study guide. Each technique is described well enough to
recognise it in a log, an alert or a scenario and to pick the control that stops or reveals it. Tools are named with
their purpose only. There are no commands, payloads or step-by-step procedures.

Every fact was checked against at least two independent sources, or against the document that defines it (a
specification or vendor reference is the authority on its own content). **verify** marks EC-Council-specific lists
and labels (tag `ec-council-specific`) and facts backed by a single source.

Checked on 2026-09-27. 219 URLs tested with curl and a browser User-Agent; all 200 except the ones removed below.
Removed after a 404: Microsoft event page 4728; NIST glossary slugs "privilege escalation", "dictionary attack",
"rainbow table", "keystroke logger", "password spraying", "credential stuffing", "secure boot", "steganalysis";
Kali "aide". Replaced: steghide.sourceforge.net and rkhunter.sourceforge.net (403) and project-rainbowcrack.com (no
answer) by their Kali tool pages. CISA "require-multifactor-authentication" answers 403 (bot protection) and is not
cited. The NIST glossary "salt" page only defines the RSA-PSS salt and "file integrity monitoring" has no
definition: neither is cited.

**ATT&CK changed in April 2026.** TA0005 is now **Stealth** (was Defense Evasion) and a new tactic **TA0112
Defense Impairment** holds the techniques that break defenses. "Clear Windows Event Logs" moved from T1070.001 to
**T1685.005** (Disable or Modify Tools: Clear Windows Event Logs), "Clear Linux or Mac System Logs" to **T1685.006**
and "Disable Windows Event Logging" to **T1685.001**; the old URLs redirect. Indicator Removal (T1070: Timestomp,
File Deletion, Clear Command History) stays under Stealth. T1574.001 is now named "DLL" (it merged the old search
order hijacking and side-loading entries). Items therefore name techniques and tactics, not IDs.

## Gaining Access

| Fact | Sources | verify |
|---|---|---|
| Windows stores local account password hashes in the SAM; domain hashes live in the AD database NTDS.dit on domain controllers; the LSASS process holds credentials of signed-in users in memory. Credential dumping targets all three. | ATT&CK T1003, T1003.001 (LSASS Memory), T1003.002 (Security Account Manager), T1003.003 (NTDS); Microsoft Learn Credential Guard overview | no |
| The LM hash is weak and legacy; the policy "Do not store LAN Manager hash value on next password change" is enabled by default since Windows Vista / Server 2008. | Microsoft Learn security policy page for that setting; Microsoft Learn NTLM overview | no |
| NTLM is a challenge-response protocol; Kerberos v5 (KDC, ticket-granting ticket, service tickets) is the preferred protocol in Active Directory. | Microsoft Learn NTLM overview; Microsoft Learn Kerberos authentication overview | no |
| Password guessing (T1110.001): many passwords against one or few accounts; causes failed logons on the same account and lockouts. | ATT&CK T1110.001; OWASP Brute force attack | no |
| Password cracking (T1110.002): offline recovery of plaintext from hashes taken from the system; it happens off the target, so the target logs show the earlier hash theft, not the guesses. | ATT&CK T1110.002; OWASP Password Storage Cheat Sheet | no |
| Password spraying (T1110.003): one or a few common passwords tried against many accounts to stay under the lockout threshold. Log signature: failed logons spread across many accounts from one source, few per account. MITRE notes LDAP/Kerberos attempts may avoid event 4625 (Kerberos pre-auth failures are event 4771, code 0x18). | ATT&CK T1110.003; OWASP Password Spraying Attack; Microsoft password spray playbook; Microsoft event 4771 | no |
| Credential stuffing (T1110.004): username/password pairs leaked from another breach are replayed against a different service; works because of password reuse. Signature: many logins from many IPs with a high share of unknown usernames and some successes. | ATT&CK T1110.004; OWASP Credential stuffing; OWASP Credential Stuffing Prevention Cheat Sheet | no |
| Dictionary, brute-force (all combinations), hybrid and rule-based/mask attacks are guess-generation strategies; rainbow tables are precomputed hash chains (time-memory trade-off) defeated by unique salts. | NIST glossary "brute force password attack"; Kali rainbowcrack page; OWASP Password Storage Cheat Sheet | no |
| EC-Council classes password attacks as non-electronic (shoulder surfing, social engineering, dumpster diving), active online (guessing, dictionary, brute force, spraying, hash injection / pass-the-hash, LLMNR/NBT-NS poisoning, keyloggers), passive online (sniffing, man-in-the-middle, replay) and offline (rainbow tables, distributed cracking). | EC-Council course page (topic "Password Attacks"); ATT&CK T1110, T1557.001, T1040, T1056.001 for the techniques themselves | **yes** |
| Pass the hash (T1550.002): the NT hash is used to authenticate over NTLM without knowing the password. Pass the ticket (T1550.003): a stolen Kerberos ticket is reused. | ATT&CK T1550.002, T1550.003; Microsoft Learn Credential Guard overview (protects NTLM hashes and TGTs) | no |
| Kerberoasting (T1558.003): any domain user requests service tickets for accounts with an SPN; RC4-encrypted parts are cracked offline. Detection: event 4769 with ticket encryption type 0x17 (RC4) and unusual numbers of requests. Mitigations: AES instead of RC4, long (25+ characters) service-account passwords, managed service accounts. | ATT&CK T1558.003 (incl. detection DET0157); Microsoft event 4769 (0x17 = RC4-HMAC) | no |
| AS-REP roasting (T1558.004) targets accounts with Kerberos pre-authentication disabled; fix: keep pre-authentication on. | ATT&CK T1558.004; Microsoft event 4768 | no |
| Golden ticket (T1558.001) = forged TGT made with the krbtgt hash; silver ticket (T1558.002) = forged service ticket made with a service account hash. | ATT&CK T1558.001, T1558.002 | no |
| LLMNR/NBT-NS poisoning (T1557.001): a host on the LAN answers failed name lookups and captures NTLM authentication; fix: disable LLMNR and NBT-NS, require SMB signing. Tool: Responder. | ATT&CK T1557.001; ATT&CK Responder S0174; Kali responder page | no |
| Keylogging (T1056.001) and network sniffing (T1040) capture credentials in transit or at input. | ATT&CK T1056.001, T1040 | no |
| MFA request generation / MFA fatigue (T1621): repeated push prompts until a user accepts; fix: number matching, phishing-resistant MFA, alerting. | ATT&CK T1621; ATT&CK M1032 | no |
| Windows logon events: 4624 success, 4625 failure (Status 0xC000006A bad password, 0xC0000064 unknown user, 0xC0000234 locked out), 4740 account locked out, 4776 NTLM credential validation, 4768 TGT requested, 4771 Kerberos pre-auth failed. | Microsoft Learn event pages 4624, 4625, 4740, 4776, 4768, 4771; Microsoft Appendix L events to monitor | no |
| NIST SP 800-63B-4: single-factor passwords at least 15 characters (8 if only used with MFA); allow at least 64; no composition rules; no periodic change unless compromise; compare against a blocklist; rate-limit to no more than 100 consecutive failures; store salted with a password hashing scheme and cost factor; salt at least 32 bits. | NIST SP 800-63B-4 §3.1.1.2, §3.2.2, §3.1.1.2 storage (HTML and landing page) | no |
| OWASP password storage: Argon2id first choice, then scrypt, bcrypt, PBKDF2 (FIPS); unique salt per password; optional pepper kept outside the database. | OWASP Password Storage Cheat Sheet; NIST SP 800-63B-4 | no |
| Account lockout threshold: Microsoft documents the setting and the trade-off (lockout helps against guessing but enables denial of service); Microsoft's baseline uses 10, CIS benchmarks recommend 5 or fewer (not 0). | Microsoft Learn "Account lockout threshold"; CIS Benchmarks page (value in the benchmark PDF, registration needed) | **yes** (exact values) |
| Microsoft Entra smart lockout separates familiar and unfamiliar locations with separate counters; Entra Password Protection bans common and custom weak passwords. | Microsoft Learn smart lockout; Microsoft Learn banned passwords | no |
| Windows LAPS rotates a unique local administrator password per device and backs it up to AD or Entra ID; stops one shared local admin password from enabling lateral movement. | Microsoft Learn Windows LAPS overview; ATT&CK M1026 | no |
| Credential Guard uses virtualization-based security to isolate NTLM hashes, Kerberos TGTs and stored domain credentials; LSA protection (RunAsPPL) runs LSASS as a protected process that blocks memory reads and code injection by non-protected processes; the Protected Users group stops NTLM caching, DES/RC4 keys and delegation for its members. | Microsoft Learn Credential Guard overview and "how it works"; Microsoft Learn additional LSA protection; Microsoft Learn Protected Users; ATT&CK M1043 | no |
| Multi-factor authentication (M1032) and account-use policies such as lockout and conditional access (M1036) are ATT&CK's main mitigations for Brute Force. | ATT&CK T1110 mitigations; ATT&CK M1032, M1036, M1027 | no |
| Exploitation to gain access: of public-facing or remote services (T1210) or of client applications through a crafted file or page (T1203). Update Software (M1051) and Exploit Protection (M1050) are the mitigations. | ATT&CK T1210, T1203, M1051, M1050 | no |
| Buffer overflow: more input than the buffer holds overwrites adjacent memory; can crash a program or run injected code. Defenses: DEP/NX, ASLR, stack canaries, Control Flow Guard, bounds-checked code. | NIST glossary "buffer overflow"; Microsoft Learn exploit protection reference (DEP, ASLR, CFG settings) | no |
| Tools by purpose: John the Ripper and Hashcat (offline password crackers), Hydra and Medusa (online logon guessers), RainbowCrack and Ophcrack (rainbow-table crackers), Responder (LLMNR/NBT-NS poisoner), Mimikatz, pwdump, gsecdump, Windows Credential Editor and LaZagne (credential dumpers / password recovery), Rubeus and Impacket (Kerberos and protocol toolkits), Metasploit Framework (exploitation framework), Exploit-DB (public exploit archive). | Kali pages john, hashcat, hydra, medusa, rainbowcrack, ophcrack, responder, metasploit-framework; ATT&CK software S0002, S0006, S0008, S0005, S0349, S1071, S0357; openwall.com/john; hashcat.net; exploit-db.com | no |
| AI-powered exploitation and system-hacking tools are an EC-Council v13 topic; no stable public tool list backs specific names. | EC-Council course page only | **yes** |

## Escalating Privileges

| Fact | Sources | verify |
|---|---|---|
| Vertical escalation = moving to a higher privilege level (user to administrator/root/SYSTEM); horizontal = acting as another account at the same level. | ATT&CK TA0004; NIST glossary "least privilege" (principle the escalation breaks) | **yes** (horizontal/vertical are common study terms, not ATT&CK terms) |
| Exploitation for Privilege Escalation (T1068): a software or kernel vulnerability gives higher rights; mitigations: update software, exploit protection, application control, threat intelligence on vulnerable drivers. | ATT&CK T1068; ATT&CK M1051, M1050, M1038 | no |
| Abuse Elevation Control Mechanism (T1548): Bypass UAC (.002), Setuid and Setgid (.001), Sudo and Sudo Caching (.003). | ATT&CK T1548, T1548.001, T1548.002, T1548.003 | no |
| UAC: administrators run with a standard-user token until they approve elevation; Windows marks processes with integrity levels (low, medium, high, system) and lower levels cannot modify higher ones. Hardening: set UAC to "always notify", users without local admin rights. | Microsoft Learn UAC overview and "how UAC works"; ATT&CK M1052, M1026 | no |
| setuid/setgid programs run with the file owner's or group's rights; a writable or unnecessary setuid-root binary is an escalation path. Hardening: audit setuid files, mount user-writable filesystems `nosuid`, use capabilities narrowly. | man7 setuid(2), capabilities(7), mount(8); ATT&CK T1548.001 | no |
| sudo is controlled by sudoers; over-broad rules (all commands, editors or shells as root, NOPASSWD) let a user reach root. Hardening: least-privilege sudoers rules, keep `timestamp_timeout` short, review sudoers. | sudo.ws sudoers manual; ATT&CK T1548.003 | no |
| Hijack Execution Flow (T1574): DLL placement/search-order abuse (.001 "DLL"), PATH interception (.007), unquoted service paths (.009), weak service file permissions (.010). Mitigations: restrict file and directory permissions, quote service paths, application control, audit. | ATT&CK T1574 and sub-techniques .001, .007, .009, .010; Microsoft Learn DLL search order; ATT&CK M1022, M1047 | no |
| Access Token Manipulation (T1134): a process takes or impersonates another user's token (e.g. SYSTEM). An access token holds the user's SID, groups and privileges. | ATT&CK T1134; Microsoft Learn access tokens | no |
| Scheduled tasks/cron (T1053) and services (T1543) created or modified by a user who can write to them run with the task's or service's rights; the same techniques give persistence. | ATT&CK T1053, T1053.003, T1053.005, T1543.002, T1543.003 | no |
| Escape to Host (T1611): breaking out of a container to the host; mitigations: no privileged containers, least-privilege runtime, patch the runtime and kernel. | ATT&CK T1611 | no |
| Detection: event 4672 (special privileges assigned to a new logon), 4688 process creation with elevated token, 4732 member added to a local security group, 4697 service installed, 4698 scheduled task created; Sysmon event 1 (process creation). | Microsoft event pages 4672, 4688, 4732, 4697, 4698; Sysmon page | no |
| Least privilege, privileged account management (separate admin accounts, tiered access, privileged access workstations) and patching are the core hardening controls. | NIST glossary "least privilege"; Microsoft Learn privileged access model; Microsoft Learn least-privilege administrative models; ATT&CK M1026 | no |
| Privilege-escalation checkers by purpose: PEASS-ng (LinPEAS/WinPEAS) and PowerSploit's PowerUp list likely local escalation paths; BloodHound maps Active Directory relationships and attack paths. Defenders run the same tools to find paths first. | Kali peass-ng page; ATT&CK PowerSploit S0194; ATT&CK BloodHound S0521 | no |
