# Research: M9 Social Engineering

Scope: the five sections in `content/modules/m09/meta.json`. The public CEH v13 course page lists the module's
key topics (social engineering and its types, human-based techniques, impersonation, computer-based techniques,
phishing and phishing tools, impersonation using AI, identity theft, mobile-based techniques, countermeasures,
anti-phishing toolbar) and three labs (social engineering techniques, detecting a phishing attack, social
engineering using AI). That list is used for scope only; all wording below is ours, from public primary sources.

Level: recognition and defense. The module explains how each technique works well enough to spot it and stop it;
it contains no ready-to-use phishing templates or pretext scripts.

Every fact was checked against at least two independent sources. **verify** marks EC-Council-specific lists and
labels (tag `ec-council-specific`) and facts backed by a single source.

Checked on 2026-09-23. URLs tested with curl and a browser User-Agent: all 200, except FBI, FCC and
media.defense.gov pages (403 from bot protection, pages exist) and TryHackMe (429). Removed (404): NIST glossary
slugs for spear phishing, whaling, pretexting, tailgating, piggybacking, shoulder surfing, dumpster diving,
identity theft, vishing, smishing, baiting, impersonation, typosquatting, deepfake, mantrap, elicitation, quid pro
quo; NCSC "business-email-compromise", "insider-risk", "suspicious-messages"; FTC "social-media-scams". Note:
ATT&CK T1656 (Impersonation) now redirects to **T1684.001** (Social Engineering: Impersonation, created April 2026);
we cite the new ID.

## Social Engineering Concepts

| Fact | Sources | verify |
|---|---|---|
| Social engineering = tricking or deceiving a person into revealing information (for example a password) or taking an action that helps an attack. | NIST CSRC glossary "social engineering" (SP 800-115, SP 800-82r3); CISA "Avoiding Social Engineering and Phishing Attacks" | no |
| The attacker uses human interaction and may piece information together from several people in the same organization, using what one source said to gain credibility with the next. | CISA "Avoiding Social Engineering and Phishing Attacks"; MITRE ATT&CK T1598 (Phishing for Information) | no |
| Levers that make targets comply: authority, urgency, emotion (fear, curiosity, hope), scarcity, current events; also trust in a known sender. | NCSC "Spot scams" (authority, urgency, emotion, scarcity, current events); MITRE ATT&CK T1684.001 (urgent, payment, request wording; trusted sender) | no |
| EC-Council's list of reasons social engineering works: authority, intimidation, consensus (social proof), scarcity, urgency, familiarity (liking), trust, greed. | EC-Council course page (scope only); NCSC "Spot scams" (overlapping subset) | **yes** (`ec-council-specific`) |
| EC-Council's four phases of a social engineering attack: research the target company → select a target person → develop a relationship → exploit the relationship. | EC-Council framing; CISA page describes the same research-then-exploit pattern | **yes** (`ec-council-specific`) |
| EC-Council's factors that make companies vulnerable: insufficient training, unregulated access to information, several organizational units, missing security policies. | EC-Council framing; NCSC phishing guidance (reliance on users, reporting culture) | **yes** (`ec-council-specific`) |
| Three families: human-based (in person, phone), computer-based (email, web, chat, social media), mobile-based (SMS, apps, QR). | EC-Council course page (topic names); MITRE T1566 (electronic delivery) and T1660 (mobile) | **yes** (grouping is EC's) |
| ATT&CK: T1566 Phishing (Initial Access, goal = run code or get access) vs T1598 Phishing for Information (Reconnaissance, goal = collect data such as credentials). Sub-techniques: attachment, link, via service, voice. | MITRE ATT&CK T1566 and T1598 pages and their sub-technique pages | no |
| ATT&CK T1684 Social Engineering (2026) covers trust-building across email, collaboration, voice (including AI voice) and help desk to get password resets, MFA changes or payments approved; T1684.001 Impersonation, T1684.002 Email Spoofing. | MITRE ATT&CK T1684, T1684.001, T1684.002 | no |
| Impact on an organization: financial loss (for example BEC wire fraud), data and credential loss, reputation damage, legal exposure. | FBI "Business Email Compromise"; CISA insider threat definition (harm to CIA) | no |

## Human-based Techniques

| Fact | Sources | verify |
|---|---|---|
| Impersonation: posing as a trusted person (new employee, repair person, executive, vendor, help desk) to get information or an action. | CISA "Avoiding Social Engineering…"; MITRE ATT&CK T1684.001 | no |
| Vishing = social engineering by voice; VoIP lets caller ID be spoofed. | CISA "Avoiding Social Engineering…"; MITRE ATT&CK T1566.004 / T1598.004 (spearphishing voice) | no |
| Caller ID spoofing: falsifying the number shown to the called party. | FCC "Caller ID Spoofing" (403, exists); CISA vishing paragraph | no |
| Spoofing covers impersonating, masquerading, piggybacking and mimicking. | NIST glossary "spoofing" (CNSSI 4009); NIST IR 8323r1 | no |
| Piggybacking vs tailgating (EC-Council): piggybacking = an authorized person knowingly lets the attacker in (for example "forgot my badge"); tailgating = the attacker slips in behind without the authorized person's consent. Many sources use the words as synonyms. | EC-Council framing; CISA defining insider threats (negligent insider "allowing someone to piggyback") | **yes** (`ec-council-specific`) |
| Shoulder surfing, eavesdropping and dumpster diving are close-in techniques that gather passwords, PINs, names and internal documents; defenses are privacy screens, clean-desk policy, shredding and locked bins. | CISA "Avoiding Social Engineering…" (do not reveal internal information); NIST SP 800-88r1 (media sanitization before disposal) | **yes** (no primary glossary entry for these terms) |
| Reverse social engineering: the attacker creates a problem, advertises as the helper, and the victim calls the attacker. | EC-Council framing; FTC tech-support scams (pop-up tells victim to call a number) | **yes** |
| Quid pro quo (something for something: "free help" in return for credentials), baiting (infected USB or free download left as bait), honey trap (romantic lure), diversion theft, elicitation (steering conversation to extract facts). | EC-Council framing; MITRE ATT&CK T1091 (malware on removable media relies on users), FTC romance scams | **yes** |
| Insider threat = an insider uses authorized access or knowledge, wittingly or unwittingly, to harm the organization. | NIST glossary "insider threat" and "insider" (RFC 4949); CISA "Insider Threat Mitigation" | no |
| CISA types: unintentional (negligent, accidental), intentional (malicious), collusive (insider working with an outsider), third-party (contractors, vendors). | CISA "Defining Insider Threats"; CISA Insider Threat Mitigation Guide | no |
| EC-Council insider types: malicious, negligent, professional, compromised. | EC-Council framing; CISA list overlaps (malicious, negligent, collusive) | **yes** (`ec-council-specific`) |
| Most insiders do not join to do harm; motivation builds over time through stressors, so behavioral indicators matter. Program: detect and identify, assess, manage. | SEI CERT Insider Threat Center; CISA "Insider Threat Mitigation" | no |
| AI impersonation: voice cloning from a short clip, deepfake video calls with "executives", AI-written text to scale spear phishing. Defense: verify through a known channel, agreed secret word. | FBI IC3 PSA241203; FTC "Scammers use AI to enhance their family emergency schemes"; NSA/FBI/CISA "Contextualizing Deepfake Threats" (403, exists) | no |

## Computer-based Techniques

| Fact | Sources | verify |
|---|---|---|
| Phishing: fraudulent solicitation by email or website that masquerades as a legitimate business or person to get sensitive data. | NIST glossary "phishing" (RFC 4949); CISA "Avoiding Social Engineering…" | no |
| Spearphishing targets a specific person, company or industry; mass phishing is untargeted. | MITRE ATT&CK T1566; CISA "Avoiding Social Engineering…" | no |
| Whaling = spear phishing aimed at senior executives. | EC-Council framing; MITRE T1684.001 (executive impersonation in BEC) | **yes** |
| Pharming: redirecting users to a fake site by technical means (DNS or hosts file poisoning) so no bad link needs to be clicked. | NIST glossary "pharming" (SP 800-44, SP 800-63); CISA page (spoofed sites) | no |
| Watering hole: compromise a site the target group visits; ATT&CK Drive-by Compromise. | NIST glossary "watering hole attack"; MITRE ATT&CK T1189 | no |
| Business email compromise: impersonate an executive or supplier by email to get payments or data; wording like urgent, payment, request. | MITRE ATT&CK T1684.001; FBI "Business Email Compromise" (403, exists) | no |
| Email spoofing: forged From header; enterprise defenses are SPF, DKIM, DMARC. | MITRE ATT&CK T1684.002; Microsoft "Email authentication in Microsoft 365" | no |
| Look-alike domains (character swaps, homoglyphs, different TLD) and URL shorteners hide the real destination. | CISA "Avoiding Social Engineering…" (indicators); MITRE ATT&CK T1583.001 (domains similar to legitimate ones) | no |
| Phishing indicators: suspicious sender address, generic greeting and missing contact details, links whose target differs from the text, poor spelling and layout, unexpected attachments, urgency. | CISA "Avoiding Social Engineering…"; FTC "How to recognize and avoid phishing scams" | no |
| Spearphishing via service: through social media or webmail (for example fake recruiter contact) where enterprise controls are weaker. | MITRE ATT&CK T1566.003; T1598.001 | no |
| Internal spearphishing: a compromised internal account phishes colleagues. | MITRE ATT&CK T1534; T1684.001 | no |
| Impersonation on social networks: fake or hijacked profiles build trust, then ask for data or money or push malware; persona building is ATT&CK T1585.001; adversaries also mine social media (T1593.001). | MITRE ATT&CK T1585.001, T1593.001; NCSC "Social media: how to use it safely"; CISA "Staying safe on social networking sites" | no |
| Spimming (spam over instant messaging), angler phishing (fake customer-support accounts), catfishing, hoax and chain letters, pop-up scareware. | EC-Council framing; FTC tech-support scams (pop-ups) | **yes** |
| Identity theft: using someone's personal or financial data without permission (names, card or bank numbers, SSN, insurance numbers). Kinds include financial, medical, tax, child, criminal, synthetic. | FTC "What to know about identity theft"; IdentityTheft.gov (more than 30 types) | no |
| Medical identity theft: using someone's data to get care, drugs or insurance payments. | FTC "Medical identity theft"; IdentityTheft.gov | no |
| Synthetic identity fraud: combining real and fake PII to fabricate a person. | Federal Reserve FedPayments Improvement "Synthetic identity fraud"; IdentityTheft.gov | no |
| Tools: Social-Engineer Toolkit (SET, `setoolkit`, TrustedSec, open source, for authorized assessments); Gophish (open-source phishing simulation framework); Evilginx (adversary-in-the-middle proxy that captures credentials and session cookies, defeating OTP-style MFA); Microsoft Attack Simulation Training (payload types: credential harvest, malware attachment, link in attachment, link to malware, drive-by, OAuth consent grant). | SET GitHub + Kali tools page; getgophish.com + Gophish docs; Evilginx GitHub + MITRE T1557; Microsoft Learn attack simulation | no |

## Mobile-based Techniques

| Fact | Sources | verify |
|---|---|---|
| Smishing = phishing by SMS; links, numbers or callback requests with urgency. Report by forwarding to 7726 (SPAM). | CISA "Avoiding Social Engineering…"; FTC "How to recognize and report spam text messages"; MITRE ATT&CK T1660 | no |
| Quishing = QR codes that lead to phishing sites, for example stickers over parking-meter codes. | MITRE ATT&CK T1660; FTC consumer alert on QR codes; APWG trends report (millions of QR emails) | no |
| SIM swap: the attacker impersonates the victim to the carrier to move the number to their SIM, then receives SMS codes. Defenses: carrier PIN or port-out lock, non-SMS MFA. | MITRE ATT&CK Mobile T1451; FTC "SIM swap scams" | no |
| Malicious, fake and repackaged apps: masquerade as legitimate apps (names, icons); install from official stores, keep Play Protect on; app integrity checks resist repackaging. | MITRE ATT&CK Mobile T1655 (Masquerading); Google Play Protect help; OWASP MASVS-RESILIENCE (tampering) | **yes** (EC-Council list "publishing malicious apps, repackaging legitimate apps, fake security apps") |
| MFA fatigue (push bombing): repeated push prompts until the user approves. | MITRE ATT&CK T1621; CISA MFA page (number matching, phishing-resistant MFA) | no |

## Social Engineering Countermeasures

| Fact | Sources | verify |
|---|---|---|
| Multi-layered defense beats "train users to spot everything": (1) make it hard to reach users, (2) help users identify and report, (3) limit the effect of a click, (4) respond quickly. | NCSC "Phishing attacks: defending your organisation"; CISA "Phishing guidance: stopping the attack cycle at phase one" | no |
| User training (M1017) plus email authentication and anti-spoofing (M1054), content restriction (M1021), network intrusion prevention (M1031), antivirus (M1049) are ATT&CK mitigations for T1566. | MITRE ATT&CK T1566 mitigations; M1017, M1054, M1021 pages | no |
| SPF (RFC 7208) lists the servers allowed to send for a domain; DKIM (RFC 6376) signs messages with a domain key; DMARC (RFC 7489) tells receivers what to do when both fail alignment (`p=none`, `quarantine`, `reject`) and where to send reports. | RFCs 7208, 6376, 7489; NIST SP 800-177r1; Microsoft email authentication | no |
| Phishing-resistant authentication binds the output to the real site (channel binding or verifier name binding); OTP and push codes typed by the user are not phishing-resistant. FIDO2/WebAuthn (passkeys, security keys) is the widely available phishing-resistant option. | NIST SP 800-63B-4; CISA MFA page and fact sheet; FIDO Alliance passkeys | no |
| Verify requests through a separate, known channel (call back a number you already have), never the contact details in the message. | CISA "Avoiding Social Engineering…"; FTC phishing page; FTC voice-cloning alert | no |
| Security awareness and training program as a life cycle with metrics. | NIST SP 800-50r1; CISA "Teach employees to avoid phishing" | no |
| Insider controls: least privilege, separation of duties, monitoring, prompt offboarding, a program to detect, assess and manage. | NIST glossary "separation of duty", "least privilege"; CISA Insider Threat Mitigation Guide | no |
| Identity theft response: report and get a recovery plan at IdentityTheft.gov; credit freeze (free, blocks new credit); initial fraud alert (1 year), extended fraud alert (7 years, needs an identity theft report). | FTC "What to know about identity theft"; FTC "Credit freezes and fraud alerts"; IdentityTheft.gov | no |
| Reporting channels: forward phishing emails to reportphishing@apwg.org, to the NCSC Suspicious Email Reporting Service in the UK, texts to 7726; FTC ReportFraud; IC3 for BEC. | APWG "Report phishing"; FTC phishing page; NCSC "Report scam email"; IC3 | no |
| Social media hygiene: restrictive privacy settings, careful with third-party apps, verified badges and reporting fake profiles. | CISA "Staying safe on social networking sites"; NCSC "Social media: how to use it safely" | no |
| Anti-phishing toolbars and reputation feeds: Netcraft extension (blocks known phishing, reports URLs), PhishTank (community phishing data, operated by Cisco Talos), Google Safe Browsing. | Netcraft browser extension page; PhishTank; Google Safe Browsing | no |
| Physical countermeasures: badges, visitor escort, access vestibules (mantraps), turnstiles, shredding, clean desk. | CISA physical security topic; diagnostic item 9001 sources (NIST glossary, CISA) | **yes** (no single primary list) |
